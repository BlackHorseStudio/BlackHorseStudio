# Black Horse Studio

**Indie game studio — Unity · C#**
We prototype fast, build playable demos, and focus on player-first design.
(2D today — moving toward 2.5D / 3D with Unity)

---

## 🚩 Quick facts

* **Team size:** 7
* **Primary platform:** Mobile (Unity)
* **Primary languages / tools:** Unity, C#; FL Studio for audio. Artists/animator use their preferred professional tools.
* **Current status:** Early stage — organization & tooling setup. Public repos and prototypes coming soon.

---

## What we build

We design and ship compact, player-focused mobile experiences with rapid iteration cycles.

* **Short-term:** Polished 2D prototypes and mobile games.
* **Mid-term:** 2.5D / 3D projects while keeping Unity as our main engine.

**Core pillars**

* Rapid prototyping → validate mechanics quickly
* Playable demos → showcaseable builds for partners and investors
* Player-first design → clear UX and feedback loops
